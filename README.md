# 📝 Lista de Tarefas (To-do List)

Aplicação web simples para organizar tarefas do dia a dia. Dá para adicionar, concluir, editar e remover tarefas, além de pesquisar por texto e filtrar por status — tudo direto no navegador, sem dependências ou etapa de build.

## ✨ Funcionalidades

- **Adicionar tarefas** pelo campo "Adicione sua tarefa".
- **Concluir tarefas**: a tarefa fica destacada e com o texto riscado.
- **Editar tarefas** em um formulário próprio, com opção de cancelar a edição.
- **Remover tarefas** individualmente.
- **Pesquisar** tarefas por texto, com botão para limpar a busca.
- **Filtrar** a lista por status: *Todos*, *Feitos* ou *A fazer*.

## 🚀 Como executar

Não é necessário instalar nada.

1. Clone o repositório:

   ```bash
   git clone https://github.com/jotapefp/To-do-List.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd To-do-List
   ```

3. Abra o arquivo `index.html` no navegador (duplo clique ou, se preferir, use uma extensão como o *Live Server* do VS Code).

> Os ícones dependem de conexão com a internet, pois o Font Awesome é carregado por CDN.

## 🧭 Como usar

1. Digite a tarefa no campo **"O que você vai fazer?"** e clique em **+** para adicioná-la.
2. Use o botão **✓** para marcar a tarefa como concluída.
3. Use o botão **✏️** para editar o texto e confirme em **✓✓** (ou clique em **Cancelar**).
4. Use o botão **✕** para remover a tarefa.
5. Digite no campo **Pesquisar** para encontrar tarefas pelo texto.
6. Escolha uma opção em **Filtrar** para ver apenas as tarefas feitas ou as que ainda faltam.
